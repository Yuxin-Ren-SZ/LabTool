Reference gene(s)
ΔΔCq needs ≥2 genes with Cq (≥1 reference + ≥1 gene of interest), named samples, and ≥2 groups. Label wells with Gene and Group above, pick reference gene(s), then the control group.
GroupGenen (bio) Mean ΔCqΔΔCq Fold95% CI p (ΔCq)p adj.Sig.

Two-tailed Student's t-test on ΔCq (not fold; Yuan 2006), each group vs control; n = biological replicates. p adj. = Holm across all group×gene tests (multiple-testing, MIQE #10). Error bars/CI span biological-replicate spread — the control group carries its own error bar (§5.6.3).
